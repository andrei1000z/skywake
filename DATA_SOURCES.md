# Data sources, licences and obligations

Skywake contains **no proprietary data and no scraped data**. Every source below is used under its published terms.
This file records what we use, under which licence, and what we do to comply.

| Source | Used for | Licence / terms | How Skywake complies |
|---|---|---|---|
| [ADSB.lol](https://adsb.lol) API (`api.adsb.lol/v2`) | Live aircraft positions | Data: [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). API: free, no key; published rate limits; production users asked to contact the operator | Visible attribution on the map and in *About & data*. All requests go through one rate-limited gateway that stays below the published limits, caches responses and backs off on errors. An identifying `User-Agent` with a link to this repo is sent. Data is relayed briefly and not stored as a database. |
| [VRS standing data](https://github.com/vradarserver/standing-data) | Callsign → route lookup | [CC0](https://creativecommons.org/publicdomain/zero/1.0/) | Fetched per callsign from the static files, cached for 6 h. Shown as "community data, may be wrong". |
| [OurAirports](https://ourairports.com/data/) | Airport names, codes, positions | Public domain | A filtered snapshot (`apps/web/public/data/airports.json`) is generated by `pnpm airports`. Credited in the UI. |
| [OpenFreeMap](https://openfreemap.org) | Basemap vector tiles and styles | Free public instance; no key; attribution required | Tiles are loaded directly from OpenFreeMap by the browser. They are not proxied, bulk-downloaded or cached by our service worker. Attribution stays visible on the map. |
| [OpenMapTiles](https://openmaptiles.org) schema | Tile schema used by OpenFreeMap | BSD / CC-BY | Attribution on the map. |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | Map data inside the tiles | ODbL 1.0 | "© OpenStreetMap contributors" on the map. |

## ODbL notes (ADSB.lol, OpenStreetMap)

- **Attribution:** shown on the map at all times (compact control) and in the *About & data* panel, with licence links.
- **Share-alike:** Skywake does not publish a derived database. It relays individual responses for a few seconds. If you
  fork Skywake and *store* the data (for history or playback, for example), any database you make public must be under ODbL.
- **Test fixtures:** `packages/shared/test/fixtures/` contains one captured ADSB.lol response, used only for automated tests.
  It is ODbL data and is documented as such next to the file.

## Sources considered and not used

- **OpenSky Network:** terms limit use to non-commercial and research purposes, and API access needs an account. It is not enabled.
- **airplanes.live:** requires approval for production use. It is not enabled.
- **Commercial trackers** (Flightradar24, FlightAware, etc.): proprietary. We use none of their data, code, icons or branding.
